# KICKSBASE — папка для загрузки на сервер

Это статическая версия утверждённого сайта. Сборка не требует Node.js, npm или отдельного этапа build.

## Как загрузить

1. Откройте папку `kicksbase-site-release`.
2. Загрузите **содержимое** папки в корень сайта на сервере: рядом должны лежать `index.html`, `assets/` и остальные HTML-файлы.
3. Не меняйте вложенность `assets/`: пути к товарам, логотипу и СБП-иконке относительные.
4. После загрузки откройте:
   - `/` — главная;
   - `/kicksbase-signal-catalog.html` — каталог;
   - `/kicksbase-signal-pdp.html?product=nike-kd-18` — карточка товара;
   - `/kicksbase-legal.html` — условия и персональные данные.

## Что можно менять дальше

- Карточки и текст главной — `kicksbase-direction-03-blue-field-v2.html`.
- Поведение, корзина, поиск, избранное и товарный лист — `kicksbase-direction-03-blue-field-v2.js`.
- Общий дизайн и адаптивы — `kicksbase-direction-03-blue-field-v2.css`.
- Каталог — `kicksbase-signal-catalog-v4.html`.
- Медиа и правила пяти кадров — `PRODUCT_MEDIA_MANIFEST.json` и `KICKSBASE_SITE_HANDOFF_RU.md`.

## Перед заменой товара

Сохраните единый стандарт: пять фото `1600×1200`, без обрезки, с одинаковым цветом модели и фоном `rgb(242 243 243)`. Подробные правила — в `brand-spec.md`.

## Важно

Это фронтенд-версия: корзина, избранное и вход демонстрируют сценарии в браузере. Для реальных заказов, авторизации и оплаты потребуется подключить серверные API и платёжного провайдера.
