# KICKSBASE — утверждённая визуальная система

## Токены

```css
--bg: oklch(0.982 0.003 255);
--surface: oklch(0.996 0.0015 255);
--fg: oklch(0.178 0.012 255);
--muted: oklch(0.465 0.018 255);
--border: oklch(0.87 0.012 255);
--accent: oklch(0.552 0.247 266);
```

## Типографика

- Display: `"Manrope", "Segoe UI", sans-serif`
- Body: `"PT Sans", "Trebuchet MS", sans-serif`
- Mono: `"Cascadia Mono", "SFMono-Regular", Consolas, monospace`

## Правила интерфейса

1. Светлая холодная витрина, графитовый текст и один синий акцент. Акцент используется только для ключевого действия и фокуса.
2. Шапка: логотип слева, основные разделы по центру, действия — иконками справа. На узких экранах навигация раскрывается через меню.
3. Для обуви обязательны пять кадров: боковой профиль, пара спереди под углом, ракурс 3/4, задний вид, подошва.
4. Каждый товарный кадр — `1600×1200`, `object-fit: contain`, центрирование, без обрезки и с холодным фоном `rgb(242 243 243)`.
5. Карточка раскрывает доступные размеры только при наведении мыши или навигации с клавиатуры; на сенсорных устройствах размеры доступны в карточке товара.
