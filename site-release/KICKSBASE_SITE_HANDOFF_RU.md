# KICKSBASE — карта сайта для дальнейших правок

Это рабочая версия утверждённого интерфейса. Редактируйте перечисленные файлы, а не старые `v3`, `legacy` и файлы направлений-презентаций.

## Точки входа

| Страница | Вход | Рабочий файл |
|---|---|---|
| Главная | `index.html` | `kicksbase-direction-03-blue-field-v2.html` |
| Каталог | `kicksbase-signal-catalog.html` | `kicksbase-signal-catalog-v4.html` |
| Товар | `kicksbase-signal-pdp.html?product=<id>` | открывает товарный лист на главной |
| Условия | `kicksbase-legal.html` | `kicksbase-legal.html` + `kicksbase-legal-v2.css` |

## Что является источником истины

- Общие токены, адаптивы, карточки, диалоги и интерактивные состояния: `kicksbase-direction-03-blue-field-v2.css`.
- Логика товара, избранного, корзины, поиска, подбора и товарного листа: `kicksbase-direction-03-blue-field-v2.js`.
- Карточки главной: `kicksbase-direction-03-blue-field-v2.html`.
- Карточки полного каталога: `kicksbase-signal-catalog-v4.html`.
- Медиа-стандарт и активные SKU: `PRODUCT_MEDIA_MANIFEST.json`.
- Бренд, типографика и обязательные визуальные правила: `brand-spec.md`.

## Как добавить товар

1. Добавьте карточку на главную и соответствующую карточку в каталог.
2. Укажите одинаковый `data-gallery-slug` / параметр `product` и одинаковые название, цену, описание, размеры и путь первого кадра.
3. Добавьте SKU в `activeSlugs` в `PRODUCT_MEDIA_MANIFEST.json`.
4. Подготовьте пять файлов: `<slug>-stage.png`, `<slug>-front-pair-bg.png`, затем `gallery/normalized/<slug>-3.png`, `-4.png`, `-5.png`.
5. Для всех пяти кадров сохраните размер `1600×1200`, весь товар в пределах кадра, одинаковый холодный фон и тот же цвет модели.

## Нельзя нарушать

- Не использовать `object-fit: cover` для товаров.
- Не подключать старые `gallery/*.webp` в карточку товара.
- Не менять цвет или модель между первым, вторым и остальными кадрами.
- Не добавлять второй акцентный цвет, декоративные градиенты или текст поверх обуви.
- Не менять существующие `data-od-id`: они нужны для адресных правок и тестирования.

## Проверка перед передачей

1. Главная, каталог, `?product=<id>`, избранное и корзина открываются без ошибок.
2. Каждая карточка показывает второе фото только при hover/focus; размеры не остаются раскрытыми после клика.
3. На телефоне нет горизонтального скролла, а диалог товара прокручивается внутри окна.
4. Каждая пара совпадает по цвету и модели во всех пяти кадрах.
