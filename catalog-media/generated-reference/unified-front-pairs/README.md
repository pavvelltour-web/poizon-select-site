# Logical Frame 3 Footwear Pair Derivatives

This folder contains reproducible source derivatives used only for logical
gallery frame 3 of the audited footwear and slide products. The builder places
complete existing product cutouts on a clean studio field and never mirrors an
input. Individual slides use their first and second views; existing
front-three-quarter pair sources are retained as a complete pair. It
intentionally leaves gallery frame 2 unchanged.

Run `python scripts/build_footwear_front_pair_overrides.py` before
`python scripts/build_unified_catalog_media.py --only <slug> --frame 3`.

These files are project-generated derivatives of the existing project media,
not official Poizon or manufacturer photography and not proof of an exact SKU.
Replace them through the official source pipeline when approved supplier media
and product identifiers are available.
